## 4) Типові Питання Викладача І Готові Відповіді

1. "Чому INP = N/A?"
- Бо для цього домену немає стабільних CrUX field-даних у момент зрізу, а PSI API повертав `429`.
- Тому INP-частину підтвердив реалізованою оптимізацією в коді і непрямими лабораторними метриками.

2. "Чому backlink-аналіз через конкурентів?"
- Власний профіль надто малий (`0-2` links), що прямо дозволяє fallback у вимогах лабораторної.
- Щоб аналіз був репрезентативний, зробив benchmark по 3 конкурентам.

3. "Що найважливіше ти реально змінив у коді?"
- 404/robots/canonical/sitemap у SEO-частині.
- Кешування і cache headers у backend.
- Відкладений рендер Search і фікс CLS для зображення.

4. "Що ще треба доробити після лабораторної?"
- Підтвердити на проді рівень хостингу (`http -> https`, `www/non-www`).
- Submit `sitemap.xml` у GSC і дочекатися стабільних field-метрик для INP.
